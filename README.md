# 🐱 CatPhotoApp

Proyecto de práctica de HTML creado siguiendo el curso de FreeCodeCamp. 🚀

## 🌐 Demo

[Ver el proyecto en Netlify](https://appgatos.netlify.app/)

## 🛠️ Tecnologías utilizadas

- HTML5 🌐

## 📝 Descripción

La página incluye:

- Un título principal. 📌
- Una sección sobre fotografías de gatos. 📸
- Un enlace a una galería de fotos. 🔗
- Una imagen de un gato con texto alternativo. 🖼️
